## Services

- **AI assistants & internal knowledge search:** FAQ/chatbot prototypes grounded in client-supplied documentation.
- **Workflow automation:** repetitive data processing, scheduled reports, and integrations with supported APIs.
- **Web and API improvements:** small frontend/backend features with reproducible delivery requirements.
- **Data cleanup & dashboards:** CSV/Excel transformations, quality checks and clear reporting.
- **Software QA and documentation:** test cases, bug investigation, maintenance guidance and setup documentation.

## How it works

1. Open a **Service request** issue with only non-confidential project information, desired result and optional USD budget.
2. Our AI-assisted qualification system reviews scope and prepares a *non-binding* proposal. The request is not a contract.
3. Delivery begins only after the client and operator agree on the contract, accepted deliverables and a supported payment method. No payment card or wallet secret should ever be posted publicly.
4. Results and tests are described truthfully. Work is only recorded as paid once a payment is independently confirmed.
