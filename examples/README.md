# Tested example · FAQ assistant logic

This small, standard-library-only Python script demonstrates deterministic FAQ matching, clear source attribution and a safe "unknown" fallback.

This is **not** a machine-learning system, a deployed customer project, a customer reference or proof of revenue. It is a public example of testable logic that can be integrated into a larger AI-powered customer-support workflow after requirements and data access are agreed.

Run:

```bash
cd examples
python3 -m unittest -v
python3 faq_demo.py "What does an automated weekly report include?"
```

No API key, no customer personal data, no third-party service calls, and no paid infrastructure are needed.
